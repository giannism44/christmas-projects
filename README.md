# Christmas Projects 🎄

Αυτό το repository περιέχει τρεις Java console εφαρμογές που δημιουργήθηκαν στο πλαίσιο προσωπικής εξάσκησης.

## 📌 Περιγραφή

- **project01** – Ανάλυση συνδυασμών αριθμών τύπου ΛΟΤΤΟ με διάφορα φίλτρα (άρτια, περιττά, συνεχόμενα, κ.λπ.)
- **project04** – Παιχνίδι Τρίλιζα για δύο παίκτες με έλεγχο νίκης και ισοπαλίας
- **project05** – Σύστημα κρατήσεων θέσεων σε θέατρο με δυνατότητα κράτησης και ακύρωσης

## 📝 Σημείωση

Όλες οι εφαρμογές υλοποιήθηκαν εξολοκλήρου από εμένα για εξάσκηση σε βασικές και σύνθετες έννοιες της Java.
